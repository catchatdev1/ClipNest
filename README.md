# ClipNest
ClipNest — A lightweight, open-source clipboard manager for Linux, built with Python.
Download instructions:
1. Download .zip
2. Install tkinter (python -m ktinkter)
3. Install wl-clipboard (if not installed): Ubuntu/Debian: sudo apt install wl-clipboard Red Hat: sudo dnf install epel-release sudo dnf install wl-clipboard
That's it for now! more OSes will be added to the command list later!
